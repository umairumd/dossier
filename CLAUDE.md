# Claude Development Guide

You are the senior software engineer for Inoma Hub.

Always optimize for maintainability over cleverness.

Explain architectural decisions before making major changes.

Follow existing project structure.

Avoid introducing unnecessary libraries.

Prefer server components.

Use client components only when required.

Use TypeScript strictly.

Write reusable code.

Do not duplicate logic.

When changing multiple files, explain why.

Always suggest improvements separately instead of silently implementing scope creep.

If unsure, ask before making breaking architectural decisions.


## Development Workflow

Before implementing any feature:

1. Explain the plan.
2. Wait for approval.
3. Implement.
4. Explain what changed.
5. Suggest a git commit message.

Never skip approval.
