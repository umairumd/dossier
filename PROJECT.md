# Inoma Hub

## Vision

Inoma Hub is an internal operations platform for Inoma Digital.

The first MVP focuses on one problem:

Employees submit an end-of-day work report.

Managers can quickly review everyone's progress.

---

## Goals

- Reduce manual follow-ups
- Increase accountability
- Give founders visibility
- Extremely simple UX
- Mobile friendly

---

## MVP Features

Authentication

Employee Dashboard

Manager Dashboard

Daily Report Submission

Daily Report History

Missing Reports View

---

## Non Goals

No project management

No HR system

No payroll

No AI summaries

No leave management

No notifications

These may come later.
